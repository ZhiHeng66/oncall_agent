# 企业知识服务多智能体协同平台（个人项目）

> 使用说明：本项目仍在改造过程中。投递简历前应逐项核对代码、测试和演示结果，仅保留已经完成并可解释、可复现的能力；正式使用时删除本说明。

**项目介绍：** 面向企业内部知识咨询、多源数据查询和复杂任务处理场景，设计并实现基于 Supervisor-Specialist 架构的多智能体协同平台。系统由 Supervisor Agent 统一完成请求路由、任务委派和结果聚合，协同 Knowledge、Data、Task、Reviewer 等专业 Agent，构建“意图识别—知识检索—工具调用—任务执行—结果审核—流式反馈”的完整智能体应用链路。

**技术栈：** Python、FastAPI、LangChain、LangGraph、RAG、Milvus、MCP、SSE、Pydantic、DashScope/通义千问

**个人职责：**

- **多智能体架构设计：** 基于 LangGraph 构建 Supervisor-Specialist 多智能体工作流，由 Supervisor Agent 根据用户意图动态选择 Knowledge、Data 或 Task Agent，并负责子任务分发、结果聚合和流程终止；通过 Reviewer Agent 对候选答案进行完整性和证据支撑检查。

- **Agent 通信与状态管理：** 基于 Pydantic 设计 `AgentTask`、`AgentResult`、`Evidence` 等 Agent 通信契约，通过结构化任务分发、执行结果和证据传递实现上下文隔离与多 Agent 结果聚合；使用 `thread_id` 隔离多轮会话，并以 `run_id` 关联单次请求中的 Agent 调度、工具调用和流式事件，实现并发任务隔离与执行链路追踪。

- **RAG 知识服务开发：** 实现文档上传、Markdown 结构化切分、Embedding、Milvus 向量存储和相似度检索链路；将知识检索能力封装为 Knowledge Agent，为回答保留文档来源、标题及相关片段，实现基于内部资料的证据化回答。

- **复杂任务工作流开发：** 将原有业务流程泛化为 Task Agent，基于 Plan-Execute-Replan 模式完成复杂任务拆解、逐步执行和动态重规划；设置最大执行步骤、重规划次数和图递归上限，避免长链路任务出现无限循环。

- **工具接入与权限治理：** 建设统一 Tool Registry，按照 Agent 职责分配工具白名单；通过 MCP 接入外部数据查询能力，并实现工具发现缓存、调用超时、有限重试、错误标准化和服务不可用降级。

- **流式交互与可观测性：** 基于 FastAPI 和 SSE 统一输出 Agent 路由、任务计划、工具调用、步骤完成、质量审核及文本增量等事件，使前端能够展示完整的多智能体执行过程，并通过 `run_id` 关联一次请求中的 Agent、节点和工具调用链路。
