# 企业知识服务多智能体协同平台（个人项目）

**项目介绍：** 面向企业知识咨询、实时数据查询和复杂任务处理场景，设计并实现基于 Supervisor-Specialist 架构的多智能体协同平台。系统由 Supervisor Agent 统一完成意图路由、任务委派和结果聚合，协同 Knowledge、Data、Task、Reviewer Agent，形成“意图识别—知识检索—工具调用—任务执行—结果审核—流式反馈”的完整 Agent 应用链路。

**技术栈：** Python、FastAPI、LangChain、LangGraph、Pydantic、RAG、Milvus、MCP、SSE、SQLite、DashScope/通义千问

**个人职责：**

- **负责多智能体架构设计：** 基于 LangGraph 构建 Supervisor-Specialist 工作流，由 Supervisor Agent 根据用户意图选择直接回答、单 Agent、并行 Agent 或复杂任务四类执行路径，完成 Specialist 的任务委派、结果聚合和流程终止。

- **负责企业知识库 RAG 系统开发：** 实现文档上传、结构化切分、Embedding、Milvus 向量存储和相似度检索；由 Knowledge Agent 完成知识检索和证据化回答，保留文档来源、相关片段及引用编号，并区分检索失败、结果为空和证据不足等状态。

- **负责复杂任务 Agent 开发：** 基于 Plan-Execute-Replan 模式设计 Task Agent，将复杂请求拆解为具有依赖关系的执行步骤，并根据中间结果动态调整后续计划；通过最大步骤数、重规划次数、调度轮次和图递归上限控制执行边界。

- **负责工具接入与权限治理：** 建设统一 Tool Registry，按照 Agent 职责分配工具白名单；通过 MCP 接入监控、日志和外部业务数据等只读查询能力，实现工具发现缓存、调用超时、有限重试、错误脱敏及服务不可用降级。

- **负责质量审核与通信契约设计：** 使用 Pydantic 定义任务、结果、证据、路由和审核等结构化契约；设计 Reviewer Agent 检查候选答案的完整性、证据引用和错误披露，并通过最多一次定向返工限制审核循环。

- **负责 API、状态管理与执行追踪：** 基于 FastAPI 和 SSE 输出路由决策、任务计划、工具调用及审核事件；通过 `thread_id` 实现会话隔离，通过 `run_id` 关联单次执行链路，并基于 SQLite Checkpointer 支持服务重启后的顶层会话状态恢复。
