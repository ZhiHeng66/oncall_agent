# 实验 03：RAG 基线与重排序

## 目标

用数据证明改造是否提升召回，而不是凭单个回答判断。

## 步骤

1. 从 `aiops-docs` 为每篇文档编写至少 5 个问题。
2. 标注每题期望文件和关键段落。
3. 写脚本直接调用 Retriever，记录 Top 1/3/5。
4. 计算 Recall@K 和 MRR。
5. 加入关键词召回或候选 Reranker。
6. 对相同题集重跑并统计延迟、Token 和费用。
7. 检查低分无答案样本，设置拒答阈值。
