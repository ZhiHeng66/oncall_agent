# 常见问题

## 为什么答案显示“证据不足”？

可能是文档尚未上传、索引服务不可用、检索为空或相关性低于阈值。检索失败与检索为空是不同状态，应分别排查。

## MCP 工单服务不可用会影响知识问答吗？

不会阻止无关的知识问答启动。Data Agent 会披露外部数据失败，Knowledge Agent 仍可使用已连接的知识库。

## 会保存完整思维过程吗？

不会。系统保存用户可见消息、路由与执行摘要、工具事件、证据、错误和耗时，不保存隐藏思维链。

## SQLite 是否等于生产级持久化？

不是。当前 SQLite Checkpointer 用于本地演示和重启恢复；多实例生产部署仍需替换为适合并发访问的持久化后端。
